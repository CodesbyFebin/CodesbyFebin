Renderer Choice: WebGL vs WebGPU

Three.js supports both WebGL and WebGPU renderers. WebGL is stable and widely supported; WebGPU is the future but still emerging.

WebGL (Default)

  • Wide browser support (including older devices)
  • Mature ecosystem; all examples use it
  • Standard choice for games and interactive experiences

WebGPU (Modern)

  • Better performance on modern devices (compute shaders, better memory)
  • Requires modern browsers (Chrome, Edge, Firefox nightly)
  • Use when targeting desktop/laptop users and you need compute shaders or advanced features
// WebGL (default, via R3F)
import { Canvas } from '@react-three/fiber';

export function Game() {
  return (
    <Canvas>
      <mesh>
        <sphereGeometry />
        <meshStandardMaterial color="orange" />
      </mesh>
    </Canvas>
  );
}

// WebGPU (explicit setup)
const renderer = new THREE.WebGPURenderer();
await renderer.init();  // Async initialization required

Materials: Built-In vs Custom

Three.js ships with production-ready materials. Use built-in materials first; only write custom shaders when you need something they don't provide.

Standard Materials

Material Use Case Features
MeshStandardMaterial Realistic surfaces (metals, plastics, skin) PBR, roughness, metalness, maps
MeshBasicMaterial Unlit, flat color Color, map, no lighting computation
MeshPhongMaterial Glossy surfaces (plastics, ceramics) Specular, shininess, fast rendering
MeshPhysicalMaterial Advanced PBR (clear coats, iridescence) All standard + coat + ior + transmission 
// Realistic metal sphere with PBR
const sphere = new THREE.Mesh(
  new THREE.SphereGeometry(1, 64, 64),
  new THREE.MeshStandardMaterial({
    metalness: 1.0,
    roughness: 0.2,
    color: 0xcccccc
  })
);

// Plastic cube with specular shine
const cube = new THREE.Mesh(
  new THREE.BoxGeometry(1, 1, 1),
  new THREE.MeshPhongMaterial({
    color: 0xff0000,
    shininess: 100
  })
);

TSL: Three.js Shading Language

TSL is Three.js's node-based shader language. It lets you build complex shaders without writing GLSL directly. Use it for advanced materials (custom lighting, procedural effects, advanced post-processing).

Key Concepts

  • Node materials compose shaders from reusable nodes (math, colors, texture lookups, lighting).
  • TSL runs on both WebGL and WebGPU (unlike hand-written GLSL).
  • Readable and debuggable—no opaque shader strings.
// Custom material with TSL (Node Material)
import * as THREE from 'three';
import { uv, vec2, color, texture, mx_noiseTexture } from 'three/tsl';

const canvas = document.querySelector('canvas');
const renderer = new THREE.WebGLRenderer({ canvas });

// Create a procedural noise material
const noiseTexture = mx_noiseTexture();
const material = new THREE.NodeMaterial();
material.colorNode = color(0xff00ff).mix(noiseTexture, 0.5);

const mesh = new THREE.Mesh(new THREE.PlaneGeometry(), material);
scene.add(mesh);

Loaders: Importing 3D Models

Use loaders to import external 3D models (glTF, FBX, OBJ). glTF is the standard for web.

glTF (Recommended)

  • Open standard, widely supported
  • Efficient (binary format, compression)
  • Includes animations, materials, textures
// Loading a glTF model with three.js
import { GLTFLoader } from 'three/examples/jsm/loaders/GLTFLoader.js';

const loader = new GLTFLoader();
loader.load('model.glb', (gltf) => {
  const model = gltf.scene;

  // If model has animations
  const mixer = new THREE.AnimationMixer(model);
  const action = mixer.clipAction(gltf.animations[0]);
  action.play();

  scene.add(model);
});

// Or with React + R3F (drei)
import { useGLTF } from '@react-three/drei';

export function Model() {
  const { scene, animations } = useGLTF('model.glb');
  // Use scene and animations
  return <primitive object={scene} />;
}

Performance Essentials

  • Cap pixel ratio: renderer.setPixelRatio(Math.min(devicePixelRatio, 2)) or R3F dpr={[1,2]}. Don't render 4x pixels on 4K displays.
  • Dispose resources: Three.js does not GC GPU memory. Call geometry.dispose(), material.dispose(), texture.dispose() on teardown.
  • Minimize draw calls: Target < 100 calls/frame. Use InstancedMesh or BatchedMesh for repeated objects.
  • Level-of-detail (LOD): Use simpler models for distant objects. Three.js LOD utility handles this automatically.
// Proper resource disposal
function cleanupScene() {
  scene.traverse((obj) => {
    if (obj.geometry) obj.geometry.dispose();
    if (obj.material) {
      if (Array.isArray(obj.material)) {
        obj.material.forEach(m => m.dispose());
      } else {
        obj.material.dispose();
      }
    }
  });
}

// Use LOD for distant objects
const lod = new THREE.LOD();
const mesh1 = new THREE.Mesh(lowPolyGeom, material);
const mesh2 = new THREE.Mesh(mediumPolyGeom, material);
const mesh3 = new THREE.Mesh(highPolyGeom, material);

lod.addLevel(mesh1, 0);    // 0-30 units: simple
lod.addLevel(mesh2, 30);   // 30-60: medium
lod.addLevel(mesh3, 60);   // 60+: high detail

scene.add(lod);
